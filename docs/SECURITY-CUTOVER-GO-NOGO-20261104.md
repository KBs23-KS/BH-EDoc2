## 1. เงื่อนไขระบบยืนยันตัวตนที่ใช้จริง
- [ ] เปลี่ยนการอ่าน/แก้ user จริงให้ใช้ Backend โดยไม่เปิดรหัสผ่าน/แฮชให้เบราว์เซอร์
- [ ] สำรองและตรวจสอบผู้ใช้จริงพร้อมแผนย้อนกลับ โดย **ไม่เปลี่ยน Username/Password เดิม**
- [ ] ทดสอบล็อกอินจริงครบ ผอ., รองฯ, ธุรการ, แอดมิน, ครู, หัวหน้า, รักษาการ, บัญชีระงับ

## 2. PDF / Drive
- [ ] เชื่อมเซิร์ฟเวอร์ที่ได้รับอนุญาตกับ Google Drive/Apps Script ที่ใช้งานจริงอย่างปลอดภัย
- [ ] ตรวจสิทธิ์อ่าน/โหลดไฟล์ ฉบับลงนามแล้ว ประวัติไฟล์ และลิงก์ Drive เก่าทุกประเภท
- [ ] อัปโหลดฉบับแก้ไข, ลบไฟล์รายไฟล์ และจัดการไฟล์ค้าง/ไฟล์กำพร้าได้โดยไม่ทำข้อมูลสูญหาย
- [ ] ลงนาม PDF โดย ผอ. จากต้นฉบับที่ตรวจแล้ว ไม่รับข้อมูลอ้างลายเซ็นปลอมจากเบราว์เซอร์
- [ ] ทดสอบจริงบน iPad และคอม รวมเปิด/ดาวน์โหลด PDF หลังลงนาม

## 3. Firestore Rules และฟังก์ชันที่ยังเขียนตรง
- [ ] ตรวจและย้ายหรืออนุญาตอย่างจำกัดสำหรับทุกการเขียนของครู/แอดมิน/ทะเบียน/แจ้งเตือน/รายงาน/สำรองกู้คืน
- [ ] ใช้ Rules แบบสิทธิ์ต่ำสุดและทดสอบว่าผู้อื่นอ่านบัญชี/เอกสารที่ไม่มีสิทธิ์ไม่ได้
- [ ] ตรวจซ้ำการออกเลข/ลบถาวร/คืนถังขยะ/ส่งกลับแก้ไข/ส่งต่อหัวหน้าภายใต้ Rules ใหม่

## 4. เกณฑ์ Go / No-go
- [ ] GitHub Actions + Emulator ผ่านบน commit ล่าสุด
- [ ] ทดสอบกับข้อมูลจำลองหน้าตาเหมือนระบบจริงครบทุกบทบาท/ทุกเมนู
- [ ] ทดสอบการกู้คืนจาก Backup และยืนยันว่าไม่สูญเสียเอกสาร/เลข/ประวัติ
- [ ] ตรวจรายการการเปลี่ยนแปลงโดยผู้ดูแลโรงเรียนก่อนอนุมัติ Deploy/Rules แยกจากงานทดสอบ
- [ ] มีขั้นตอนย้อนกลับที่ไม่ทำให้บัญชีเดิมเข้าไม่ได้

**สถานะ:** ยังเป็นการเตรียมโค้ดและทดสอบแยก ไม่ใช่การเปิดใช้จริง และไม่ควรอ้างว่าเสร็จสมบูรณ์จากชุดทดสอบจำลองเพียงอย่างเดียว
