# BHS E-Document — ปรับเมนูผู้บริหารและไม่บังคับเปลี่ยนรหัสผ่าน
- ผอ.: ซ่อนลิงก์เมนู “หนังสือรอเกษียณต่อ” ซึ่งเป็นชื่อสำหรับหัวหน้ากลุ่ม; **ยังเกษียณ/สั่งการจากหน้ารายละเอียดหนังสือได้เหมือนเดิม**
- ผอ. และรองฯ: ซ่อนเมนู “งานที่ได้รับมอบหมาย” เพราะระบบเกษียณตรงถึงบุคคลปัจจุบันเลือกครู/ธุรการ ส่วนงานของรองฯ อยู่ใน “งานที่ต้องดำเนินการ”
- หัวหน้ากลุ่มบริหารงาน/กลุ่มสาระที่ได้รับแต่งตั้งยังเห็นเมนู “หนังสือรอเกษียณต่อ” และครู/ธุรการยังเห็น “งานที่ได้รับมอบหมาย”
- เลิกแสดงหน้า ForcePasswordChange เมื่อผู้ใช้มีรหัสเริ่มต้น 123456 แต่ยังมีเมนูเปลี่ยนรหัสผ่านด้วยตนเอง และบัญชีผู้ใช้/รหัสเดิมไม่ถูกเปลี่ยน
- **คำเตือน:** บัญชีที่ยังใช้รหัสเริ่มต้น 123456 มีความเสี่ยงสูง ควรตั้งรหัสเฉพาะบุคคล ข้อเปลี่ยนนี้ไม่ใช่การยกระดับความปลอดภัยของการยืนยันตัวตนหรือ Firestore Rules
- ไม่แก้ฐานข้อมูล Firebase, ระบบ Backup, Google Drive, สิทธิ์ข้อมูล หรือการเกษียณ/บันทึกงาน
