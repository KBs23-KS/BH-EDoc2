# หน้าหลักครู — แสดงสรุปจำนวนเอกสารทั้งหมด

ปรับเฉพาะการ์ดสรุปของบัญชี role=teacher ตามความต้องการ:
1. หนังสือเข้า — จำนวนเอกสารประเภทหนังสือเข้าที่ครูมีสิทธิ์ดูทั้งหมด
2. หนังสือเวียน — จำนวนเอกสารประเภทหนังสือเวียนแจ้งรับทราบที่ครูมีสิทธิ์ดูทั้งหมด
3. คำสั่งโรงเรียน — จำนวนคำสั่งโรงเรียนที่ครูมีสิทธิ์ดูทั้งหมด (หัวหน้ากลุ่มก็ยังเห็นการ์ดนี้)
4. งานที่ได้รับมอบหมาย — คงรายการงานค้างตามเดิม เพราะเป็นเมนูงาน ไม่ใช่ทะเบียนเอกสาร

ตัวเลขสามหมวดแรกไม่กรองว่ารับทราบแล้วหรือยัง ไม่กรองวันที่วันนี้ ใช้ชุดเอกสารที่กรองด้วย `canReadDoc`/`canViewRouted` อยู่แล้ว และไม่รวมไฟล์ในถังขยะ

เมนูหัวหน้ากลุ่มยังอยู่ใน sidebar; การแจ้งเตือน รอรับทราบ สถานะ เอกสาร PDF และระบบ Backup ไม่เปลี่ยน
เมนูธุรการ (role=clerk), ผอ., รองฯ และแอดมิน ไม่เปลี่ยน

ทดสอบ unit ของตัวเลข และการแสดงการ์ดด้วย CI; ให้ทดสอบด้วยบัญชีครูใน Production ก่อนใช้จริง
