# เปลี่ยนข้อความปุ่ม ผอ. (คำสั่งโรงเรียนและหนังสือเวียน)

เฉพาะในหน้า “งานที่ต้องพิจารณา / ลงนาม” ของ ผอ. / แอดมินที่ดำเนินการแทน ผอ.:
- คำสั่งโรงเรียน: ปุ่ม “อนุมัติ / สั่งการ” → “ลงนาม / อนุมัติ”
- หนังสือเวียนแจ้งรับทราบ: ปุ่ม “อนุมัติ / สั่งการ” → “ลงนาม / อนุมัติ”
- หนังสือเข้า: คง “อนุมัติ / สั่งการ” เพื่อความหมายของการเกษียณและสั่งการ

**เป็นการเปลี่ยนข้อความ UI เท่านั้น** ไม่แก้สถานะ `DOC_STATUS`, การลงนาม PDF, การอัปโหลดแนบหนังสือเวียน, การอนุมัติและเผยแพร่, สิทธิ์, Firebase, Drive, Backup, หรือ audit log.

หมายเหตุที่ควรพิจารณาในอนาคต: คำสั่งโรงเรียนบังคับลงนามก่อนอนุมัติอยู่แล้ว ส่วนหนังสือเวียนยังอนุมัติได้แม้ไม่แนบไฟล์ที่ลงนาม; ปุ่มใหม่อาจทำให้เข้าใจว่าเป็นข้อบังคับสำหรับหนังสือเวียนทั้งที่ไม่ได้บังคับ
