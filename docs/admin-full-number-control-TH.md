# BHS E-Document — แอดมินจัดการเลขคำสั่ง (30 ตุลาคม 2569)

## สิ่งที่เพิ่ม
- แอดมินกำหนดเลขที่จะออกถัดไปได้เป็นเลขจำนวนเต็มบวกใดก็ได้ แยกทะเบียนและปี พ.ศ.
- เลขที่ยังแสดงในทะเบียนหรือคำสั่งใช้งานขวางการออกซ้ำ; เลขที่ยกเลิก ซ่อน หรือถูกลบไม่ขวาง
- แอดมินแก้เลขคำสั่งที่ออกแล้วได้ทุกสถานะ รวมเอกสารที่ ผอ. ลงนามแล้ว โดยแก้ทะเบียนและรายละเอียดเอกสารที่เชื่อมกันพร้อมกัน
- PDF ที่ลงนามไปแล้วคงเนื้อหาเดิม และระบบเตือนก่อนเปลี่ยนเลขในฐานข้อมูล
- แอดมินลบถาวรได้ทุกสถานะทีละรายการหรือเลือกหลายรายการ (สูงสุด 50 ต่อครั้ง) พร้อมลบเอกสารคู่และรายการเตือนใน Firestore
- ยืนยันการลบด้วยการพิมพ์ข้อความและยืนยันอีกชั้น; Audit Log ยังคงอยู่
- การกู้คืนเลขที่ยกเลิกหรือเลขทดลองที่ซ่อนแล้ว ต้องตรวจเลขใช้งานก่อน

## ข้อจำกัดสำคัญ
- ลบถาวรในที่นี้หมายถึงลบระเบียนใน Firestore ไม่ใช่ลบ PDF ที่ถูกอัปโหลดไปยัง Google Drive เพราะช่องทาง Apps Script ปัจจุบันไม่มีคำสั่งลบไฟล์ที่ผ่านการตรวจสิทธิ์
- PDF ที่ ผอ. ลงนามแล้วไม่ถูกแก้เลขภายในไฟล์ เมื่อแก้เลขทะเบียน ควรตรวจเอกสารต้นฉบับและจัดทำใหม่หากจำเป็น
- ต้องสำรองข้อมูลก่อนใช้งานจริง และตรวจ Firestore Security Rules/สิทธิ์ผู้ดูแล เพราะ UI role checking อย่างเดียวไม่เพียงพอ
- ไม่ได้ดำเนินการลบหรือแก้ไขข้อมูลจริงของโรงเรียนระหว่างการเขียนโค้ด
