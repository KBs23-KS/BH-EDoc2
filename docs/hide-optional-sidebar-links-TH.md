# ซ่อนเมนูเพิ่มเติมจากแถบด้านซ้าย — คงฟังก์ชันไว้

ซ่อน **ค้นหาเอกสารทั้งหมด** และ **ติดตามงานค้าง** จาก sidebar ของทุกบทบาท ทั้ง desktop/mobile โดยเอาออกจาก `navSections` เท่านั้น

**ยังเก็บไว้:** `menus` definitions, หน้าจอ `SearchCenter` และ `PendingReport`, ค้นหาข้ามทะเบียน, การคัดกรองงานค้าง, ฟังก์ชันภายใน, ปุ่ม **ค้นหาเอกสาร** ใน Dashboard และสิทธิ์การเข้าถึงเดิม

**คงเดิม:** เมนูอื่น (รวมส่งออกทะเบียน), บัญชีผู้ใช้, การเปลี่ยนหน้าและ scroll position, Firebase, Google Drive, Backup, PDF, การรับทราบและมอบหมายงาน

หมายเหตุ: หลังซ่อน `pending_report` จาก sidebar จะไม่มีปุ่มตรงนี้แล้ว แต่ยังสามารถเรียกหน้าจอได้ด้วยโค้ดหรือเพิ่มจุดเข้าถึงภายหลังได้โดยไม่ต้องสร้างหน้าใหม่
