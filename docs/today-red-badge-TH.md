# ปรับป้าย “ใหม่ วันนี้” ให้เด่นขึ้น

แก้เฉพาะป้าย **ใหม่ วันนี้** ในรายการหนังสือที่วันที่เอกสารตรงกับวันนี้:
- เปลี่ยนจากโทนน้ำเงิน/ม่วงเป็น **แดงสด** ขอบแดงอ่อน
- ขนาดตัวอักษร 10px (11px บนจอใหญ่) เพิ่มจากเดิมเล็กน้อย ไม่เปลี่ยนขนาดรายการโดยรวม
- กระพริบแบบ pulse ช้า ๆ ทุก 1.8 วินาที โดยป้ายไม่หายไปทั้งหมด และมีเงาสีแดงนุ่ม ๆ
- ปิดภาพเคลื่อนไหวโดยอัตโนมัติหากระบบตั้งค่า Reduced Motion
- ไม่เปลี่ยนเงื่อนไขวันที่ ข้อความ หนังสืออื่น สีสถานะอื่น ระบบเมนูหรือข้อมูล Firebase/Backup/PDF

ทดสอบด้วย unit check + build; ควรตรวจหน้าแสดงหนังสือที่ลงวันที่วันนี้ด้วยเบราว์เซอร์จริงหลัง deploy
