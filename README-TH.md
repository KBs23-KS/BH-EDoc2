## ยังไม่สมบูรณ์ / ยังไม่ควรใช้กับข้อมูลโรงเรียนจริง

1. **ข้อ 15**: หน้าใหม่ยังอาศัยรายการที่โหลดมาจาก Firestore ทั้งหมดใน `MainLayout` (onSnapshot). ระบบค้นหา/แบ่งหน้าที่อ่านจาก Firestore ทีละหน้าจริง **ยังไม่ได้ปรับครบทุกเมนู** ตามแผนแบบ B. เมื่อข้อมูลจำนวนมาก ยังคงมีปัญหาประสิทธิภาพและยอดรายงานอาจไม่ครบถ้ามีการจำกัดการโหลดในอนาคต
2. **ข้อ 14**: restore แบบ replace มีการเขียน batch หลายครั้ง และอัปโหลดไฟล์ Drive ก่อน โดยไม่มีทางทำเป็นธุรกรรมเดียวกันได้; หากล้มเหลวกลางทางหรือยังมีคนใช้งานอยู่ อาจไม่สามารถคืนสภาพระบบทุกส่วนอย่างปลอดภัย จึงต้องทดสอบ staging พร้อมปิดการใช้งานก่อนทุกครั้ง และเตรียม rollback plan แยกต่างหาก
3. ข้อ 17–24 ยังต้องทดสอบกับ Firebase Rules, indexes, โครงข้อมูลจริง และข้อมูลย้อนหลัง โรงเรียนยังไม่เคยส่งชุดทดสอบจริง
4. ระบบลงนาม PDF ต้องทดสอบบน iPad/Apple Pencil และกับ PDF หลายขนาด/หมุนหน้า/หลายไฟล์; การแทรกลายเซ็นไม่ใช่ใบรับรองลายมือชื่อดิจิทัล
5. Google Apps Script `gas/Code.gs` เป็นตัวอย่างเสริม ต้องนำไปผสานกับ backend เดิมก่อนใช้งานจริง อย่าเอาไปเขียนทับสคริปต์เดิมโดยพลการ
6. ตัวส่งออก PDF วาดด้วย Canvas: หากรายงานขนาดใหญ่มากจะใช้หน่วยความจำ/เวลา และตัวอักษรค้นหาภายใน PDF อาจไม่รองรับเพราะข้อความเป็นรูปภาพ; ต้องตรวจการพิมพ์ภาษาไทยจริง
7. ระบบแสดงสิทธิ์ใน UI และการกรองผลค้นหาต้องตรวจร่วมกับการกำหนด Firestore Rules ก่อนใช้งานจริง

## วิธีติดตั้งทดสอบ

1. ใช้ Firebase project สำหรับทดสอบ แยกจากข้อมูลโรงเรียนจริง และสร้าง Firestore index/rules ที่รองรับ query ภายหลัง
2. ติดตั้ง Node.js แล้วเข้าโฟลเดอร์โปรเจกต์ `npm install`, `npm run dev`; เมื่อตรวจเช็กครบค่อย `npm run build`
3. ตรวจค่า Firebase และ Google Apps Script URL กับสภาพแวดล้อมทดสอบก่อนเปิดหน้าเว็บ
4. ทดสอบจองเลขหลายเครื่องพร้อมกัน, สร้าง/ส่งกลับ/ลงนาม, อัปโหลด fail แล้ว retry, แก้ PDF ค้าง, ผู้รับ ณ วันเผยแพร่, รายงาน Excel/PDF, Backup/Restore ในโปรเจกต์ทดสอบ
5. ห้าม Restore แบบ replace ลงฐานข้อมูล production โดยไม่มีแผนหยุดผู้ใช้งานและสำเนาครบชุด

## คัดลอกโค้ดทั้งหมดในครั้งเดียว

ไฟล์ `BHS-EDoc-COPY-ALL.html` เป็นหน้าสำหรับคัดลอก **Python installer ฉบับเดียว** ที่ฝังซอร์สโปรเจกต์ครบทุกไฟล์แบบบีบอัดไว้ภายใน เปิดหน้านี้ในเบราว์เซอร์แล้วกด `คัดลอกโค้ดทั้งหมด` จากนั้นบันทึกข้อความที่คัดลอกเป็น `install_bhs.py` และรัน `python install_bhs.py` จะได้โฟลเดอร์โปรเจกต์ครบชุด

รหัสติดตั้งดังกล่าวเป็นการขนส่งซอร์ส ไม่ใช่โปรแกรมสำหรับเข้าไปแก้ Firebase หรือ Drive โดยอัตโนมัติ
