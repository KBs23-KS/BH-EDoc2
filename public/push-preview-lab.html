ทดสอบ Web Push จริง (Firebase แยก)

หน้านี้ใช้ทดสอบส่ง Web Push ผ่านเซิร์ฟเวอร์ Vercel ไปยังอุปกรณ์ของผู้ทดสอบเท่านั้น ข้อมูลที่จัดเก็บอยู่ใน Firebase bhs-edoc-security-test ไม่อ่านบัญชีครูหรือเอกสารจริง ไม่ใช่หน้าระบบสารบรรณ

กำลังตรวจสอบความพร้อมของเซิร์ฟเวอร์ทดสอบ...

ต้องอนุญาตการแจ้งเตือนก่อนทดลองส่งข้อความ

iPad / iPhone

เปิดลิงก์ใน Safari → แชร์ → เพิ่มไปยังหน้าจอโฮม → เปิดแอปจากหน้าจอโฮมก่อนทดสอบ Push

ทดสอบตอนปิดหน้าเว็บ: หลังเปิดรับ Push ให้สลับไปหน้าจออื่นหรือปิดแท็บก่อน แล้วกลับมาที่หน้านี้เพื่อกดส่งจากอีกอุปกรณ์ไม่ได้ เพราะการทดสอบส่งถูกล็อกให้ใช้เฉพาะอุปกรณ์ที่สมัครไว้ ทดสอบรับตอนแอปไม่อยู่เบื้องหน้าได้โดยกดส่งแล้วสลับออกอย่างรวดเร็ว

การส่งแต่ละครั้งจำกัดเว้น 60 วินาที สูงสุด 10 ครั้งต่อเครื่องต่อวัน อายุการลงทะเบียน 24 ชั่วโมง ถ้า Firebase ทดสอบยังไม่พร้อม ปุ่มจะไม่เปิดใช้งาน

กลับไปหน้าทดสอบแจ้งเตือนในเครื่อง
